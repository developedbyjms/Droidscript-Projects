# DeepNeuralNetwork

Python-based application for creating and managing machine learning models using a graphical user interface. The app facilitates tasks such as adding training data, managing datasets, training deep neural networks, and performing predictions. Key functionalities include:

1. Dataset Management:

Adding and deleting datasets.

Loading datasets from .txt files.

Managing training and prediction datasets.



2. Model Configuration:

Specifying model parameters such as the number of epochs and hidden layers.

Saving model configurations to structured folders.



3. Prediction:

Using trained models for prediction with new datasets.

Displaying prediction results through a dialog.



4. File System Interactions:

Creating and deleting directories and files on the device's storage.

Reading and writing JSON data to manage datasets and configurations.



5. Deep Learning Integration:

Uses a DeepNeuralNetwork class (imported from dnn) to handle model training and inference.



6. User Interface:

Copy the files into your Droidscript Project and run it.
N.B: The DeepNeuralNetwork.py is the main file.
